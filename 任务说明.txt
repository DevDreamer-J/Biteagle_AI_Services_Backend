后端工程

后端工程是 AI 应用落地的基础。 
学习重点不是堆技术栈，⽽是掌握异步编程、接⼝开发、数据建模、数据库访问、缓存、消息队
列、容器化、测试和⾃动化交付这些核⼼能⼒。
这样才能让 AI Agent、RAG、⼯具调⽤等能⼒可以稳定运⾏在真实服务中。 

Python Async
Python 异步编程是 AI 后端的基础能⼒。 
需要理解 asyncio、协程、事件循环、任务调度、并发控制、异步 I/O、超时取消，以及什么时候
该⽤ async、什么时候不该⽤ async。 
https://docs.python.org/3/library/asyncio.html 

FastAPI
FastAPI 是 Python 后端常⽤的异步 Web 框架。 
需要掌握路由、请求响应模型、依赖注⼊ Depends、中间件、异常处理、⽣命周期管理、
OpenAPI ⽂档和异步接⼝开发。 
https://fastapi.tiangolo.com/zh/learn/ 

Pydantic
Pydantic 是 Python 数据校验和序列化的核⼼⼯具。 
需要掌握 BaseModel、Field、类型标注、嵌套模型、枚举、校验器、配置项、DTO 设计，以及
它在 API ⼊参、出参和结构化数据建模中的作⽤。 
https://docs.pydantic.dev/latest/ 

SQLAlchemy & Alembic
SQLAlchemy 是 Python 主流 ORM，Alembic ⽤于数据库迁移。 
需要掌握 SQLAlchemy 2.0、AsyncSession、模型定义、关系映射、事务管理、查询构造、连接
池，以及数据库Schema 迁移。 
https://docs.sqlalchemy.org/en/20/orm/extensions/asyncio.html 
https://alembic.sqlalchemy.org/en/latest/ 

PostgreSQL
PostgreSQL 是后端常⽤关系型数据库，也是很多 AI 应⽤存储业务数据、会话数据、任务状态和
向量数据的基础。
需要掌握表设计、索引、事务、锁、JSONB、全⽂检索，以及 pgvector 的基本使⽤。 
https://www.postgresql.org/docs/ 
https://github.com/pgvector/pgvector 

Redis
Redis 是⾼性能内存数据库，常⽤于缓存、限流、分布式锁、会话状态、任务状态和轻量消息流。 
需要掌握 String、Hash、Set、ZSet、Stream、TTL、Pipeline、Lua、Pub/Sub、RedisJSON 
和 Vector Search。 
https://redis.io/docs/latest/ 
https://redis.io/docs/latest/develop/interact/search-and-query/ 

RabbitMQ
RabbitMQ 是基于 AMQP 的消息队列，适合异步任务、服务解耦、流量削峰和后台任务处理。 
需要掌握 Producer、Consumer、Exchange、Queue、Binding、Routing Key、Ack、
Prefetch、死信队列和 Quorum Queue。 
https://www.rabbitmq.com/tutorials 
https://www.rabbitmq.com/docs 

Testing
测试是后端⼯程质量的基本保障。
需要掌握单元测试、集成测试、异步测试、Mock、Fixture、测试数据库、接⼝测试，以及如何为
外部 API、消息队列和数据库访问编写可靠测试。 
https://docs.pytest.org/en/stable/ 
https://pytest-asyncio.readthedocs.io/en/latest/ 

Docker
Docker 是服务容器化的基础。 
需要掌握 Dockerfile、镜像构建、容器运⾏、环境变量、volume、network、multi-stage 
build、docker compose，以及本地开发环境编排。 
https://docs.docker.com/get-started/ 
https://docs.docker.com/compose/ 

Kubernetes 基础
Kubernetes 是服务部署和编排的基础。 
需要掌握 Pod、Deployment、Service、Ingress、ConfigMap、Secret、Job、CronJob、
HPA、健康检查和滚动发布。 
https://kubernetes.io/docs/concepts/ 

Microservices
微服务是围绕业务能⼒拆分服务的架构⽅式。 
需要理解单体 vs 微服务、DDD 边界、同步通信、异步通信、API ⽹关、配置管理、服务治理、可
观测性，以及什么时候不应该拆微服务。 
https://microservices.io/ 

CI/CD
CI/CD ⽤于⾃动化检查、测试、构建和部署。 
需要掌握 GitHub Actions、workflow、job、step、trigger、secrets、cache、artifact、测试流
⽔线、Docker 镜像构建和多环境部署。
https://docs.github.com/en/actions
